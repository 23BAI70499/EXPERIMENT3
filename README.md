Project Overview

This project is an experiment using BrowserRouter and Routes to demonstrate basic navigation in a React application.

It is a combination of multiple components, including:

A Home page

A Contact page

A Dashboard section

Navigation between pages is handled using a Navbar, allowing users to move between different routes easily.

Additional features include:

A Marquee component for scrolling text

Basic HTML elements such as h1 and h2 to display headings and page content

This project is mainly focused on understanding routing, component structure, and simple navigation in React.
